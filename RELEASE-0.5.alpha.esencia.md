# 0.5.alpha.esencia — Nightly PC
<!-- bt3-revision: esencia-20261125 -->

## Español

- Historia CH1–CH9 con escenas, música y textos ES/EN. Piccoro y Krilin recuperan el Makankosappo normal y el Kienzan en combate. Las técnicas guionizadas se conservan.
- Cráteres, sangre, efectos de ki, cielo y superficies. Mapas de tamaño normal y 2×. Historia CH8 puede perder cuadros con seis personajes, varios derribados y cráteres visibles.
- Selector, Pótara, vida, personajes y MAX de Zeno. Se conserva el catálogo previo y Budokai 3, y se retira música procedente de BT4/Budokai 4.
- Mejor cadencia al agrupar las subidas del renderer. Esta versión incluye el ajuste sin saltos de cuadros.

Usa Windows Setup para una instalación limpia. Windows Update Setup, el ZIP de actualización o el canal Nightly sirven para instalaciones compatibles. Para instalar desde cero hace falta una ISO admitida. Esta edición es para Windows.

## English

- Story CH1–CH9 with cutscenes, music and ES/EN text. Piccolo and Krillin use Special Beam Cannon and Destructo Disc in combat. Scripted techniques are preserved.
- Craters, blood, ki, sky and surface effects. Normal and 2× map sizes. Story CH8 may still drop frames when six fighters, bodies and craters are visible.
- Character selection, Potara, health, roster and Zeno's MAX label. The existing and Budokai 3 music catalogue remains. BT4/Budokai 4 music has been removed.
- More consistent frame timing with grouped renderer uploads and frame skipping disabled.

Use Windows Setup for a clean installation. Use Windows Update Setup, the update ZIP or the Nightly updater for a compatible existing installation. A compatible ISO is required for a clean installation. This release targets Windows.
