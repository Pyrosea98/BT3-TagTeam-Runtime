# BT3 Tag Team + Real Power Scale — 0.5.alpha (PC)

Experimental Dragon History/Saiyan Saga build, modern selection, Scenarios and existing Tag Team gameplay. Namek is unlocked as coming soon after the Saiyan saga; there are no playable Namek chapters in this alpha.

Updates and instructions: https://github.com/Pyrosea98/BT3-TagTeam-Native/releases/tag/v0.5.alpha

The PC update applies to an existing supported 0.4.1 installation, preserves saves/settings/achievements and normal/2x map choice, verifies all changed inputs and keeps rollback copies. A new ISO requires an explicit compatible import recipe; never blindly replace extracted data. No ISO, BIOS, AFS archive, personal save, build cache or diagnostic checkpoint is included here. Generated UI data are supplied by the update package; the reward chime is derived from the user's game resources.

Existing modder/asset credits remain in-game. AI assistance: Codex, Claude, DeepSeek and Qwen; Juan directs and live-tests the project.
